# Oziron agents - Statische site

Deze repository bevat de statische website voor de Google-app "Oziron agents".

## Pagina's

- `index.html` - Hoofdpagina met informatie over Oziron agents
- `privacy.html` - Privacybeleid voor gebruikersgegevens
- `terms.html` - Gebruiksvoorwaarden

## GitHub Pages

Deze site is geconfigureerd voor GitHub Pages en wordt automatisch gepubliceerd op `https://oziron-bv.github.io`.

## Lokale ontwikkeling

Open de HTML-bestanden rechtstreeks in een browser of gebruik een lokale webserver.
